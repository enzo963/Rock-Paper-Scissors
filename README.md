# Rock Paper Scissors Game 🪨📄✂️

A stylish, interactive Web-based Rock-Paper-Scissors game featuring a modern Glassmorphism interface, custom avatars, and a real-time score tracking engine. Play against the computer in a first-to-5 match!

 **[View Live Demo](https://enzo963.github.io/Rock-Paper-Scissors/)**

---

## Features

* **Player vs Computer AI:** Automated, randomized decision engine for computer moves.
* **Match Scoreboard:** Real-time score tracking displaying round-by-round results.
* **First-to-5 Victory Rule:** Automatic game conclusion and reset mechanism once a player reaches 5 points.
* **Glassmorphism UI:** A sleek, semi-transparent frosted visual box layered over custom background wallpaper.
* **Interactive Micro-Interactions:** Custom choice icons with hover scaling and active click feedback.

## Tech Stack

* **HTML5:** Layout structure and image-based interactive buttons.
* **CSS3:** Custom visual design, background image overlays, Flexbox positioning, and Glassmorphism backdrop filters (`backdrop-filter: blur()`).
* **JavaScript (ES6):** State management, match calculation logic, and event-driven DOM updates.
